# 温泉国盗りマップ

入った温泉を記録すると、日本地図が湯の色に染まっていく、47都道府県の温泉制覇マップです。

- 県ごとの温泉マップ（全国の主な温泉地 約330か所）
- 初級・中級・上級のランク分け
- 達成年月日・施設名・写真リンク・メモの記録
- 記録はブラウザ内に保存。Dropboxにも保存できます
- バックアップの書き出し・読み込み

## 使い方

https://shinichiokabe.github.io/onsen-kunitori/ を開くだけで使えます。インストールや会員登録は不要です。
